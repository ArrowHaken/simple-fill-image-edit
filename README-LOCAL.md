# CatsCo 图片素材工作台 · 交互优化版 v18

本版保留现有图像处理管线，更新了前端与编辑状态协议。

v18 修正选区显示：手动框选始终使用用户原来的同一个虚线框，确认时只从灰色变为绿色，不绘制外扩边界框、不铺色。移除双边界图例；实际修改比例仍在设置中显示，生成范围计算保持原逻辑。素材名称在工具栏垂直居中，成功保存状态不再可视显示，保存中和异常状态移至编辑面板底部。已用像素检查确认框的几何形状不变、没有第二层边界，并核实当前素材及草稿未改变。

v17 根据页面标注更新：选区和实际修改范围采用无填充虚线，缩放时保持线宽；显隐按钮同步文字、颜色与状态；步骤编号改为图标，项目名称移到画布上方居中；精简重复说明。后端预览增加目标与实际修改轮廓坐标，使用同一提交蒙版提取，不改变生成范围。`selection-renderer.js` 负责画布虚线，颜色与图例共用变量。27 项后端测试、51 项原有浏览器检查和 23 项本轮检查通过。

v16 在 v15 功能优化基础上对齐 CatsCo 主前端白天模式：本地加载 Inter / Noto Sans SC 可变字体，使用主站品牌标识、中性白灰背景、浅灰控件、统一选中与焦点状态。白字主按钮采用深绿以满足文字对比度；图片工作区使用中性灰。

视觉变量位于 `app/static/catsco-light-tokens.css`，布局和组件位于 `app/static/styles.css`。字体按字符范围分片加载，文件和授权位于 `app/static/assets/fonts`，无需外部字体 CDN。本轮重新通过 51 项原有浏览器检查及 15 项字体、对比度、弹窗、响应式和减少动态效果检查。后端未因 v16 视觉更新而修改。

## 启动

需要正常可用的 Python 3.12。使用独立虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-preview.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 7862
```

访问 http://127.0.0.1:7862/ 。前端文件修改后刷新页面；后端修改后重启服务。本机当前项目环境已经安装好依赖，可使用项目根目录的 `start-preview.ps1`。

项目数据默认存储于 `data`，可通过环境变量 `CATSCO_INPAINT_DATA` 改到其他位置。源码分发包不包含用户数据、API密钥、虚拟环境、模型权重和运行日志。旧项目可继续读取；编辑后会写入新的分底图草稿结构。

## 本轮功能

- 画布优先布局；窄窗口通过“编辑”打开面板，“项目”“任务”“导出”始终可达。
- 点击或拖入图片创建项目；自动使用文件名，可点击顶栏名称重命名。
- 框选自动保存选区并生成实际边界预览；另提供坐标输入，键盘可用。
- 清空、重新画框、修改智能选区条件会立即使旧蒙版失效。
- 绿色表示目标选区，金色表示实际提交范围；预览与生成共用范围计算。
- 提示词、选择方式、点/框、目标蒙版和范围设置按项目与底图保存；本机副本支持未同步时恢复。
- 刷新恢复当前项目与版本；对比使用当前结果的父版本。
- 同次提交有幂等标识；相同修改执行期间不会重复提交；任务订阅不随项目切换改变。
- 有本地生成图片时可继续处理；没有图片时不会以“恢复”的名义重新提交生成。
- 服务重启将运行中任务标记为中断，不自动重发生成。
- 预览覆盖层与导出独立；上传原文件完整保存。
- 原生对话框、可访问的项目/版本按钮、状态提示与减少动态效果支持。

## 当前能力边界

上传、手动框选、修改范围预览、草稿保存、版本浏览和导出可在没有AI密钥时使用。

智能选区需要 `WAVESPEED_API_KEY`。图片生成需要 `CATSCO_MASKED_IMAGE2_API_KEY` 和服务支持的 `CATSCO_MASKED_IMAGE2_BASE_URL` 等配置。项目不会自动读取 `.env`，应在启动进程前设置环境变量。服务设置面板可查看配置状态。

透明PNG的上传原文件会按原字节保存。当前局部生成使用白底RGB工作副本，结果不承诺透明背景；“导出”里可单独下载含透明通道的原文件。

本版采用单进程本地任务线程池。元数据更新在单进程内加锁；尚未提供多进程/多用户事务数据库。不要对同一数据目录启动多个服务或使用多个Uvicorn worker。重启中断的任务只支持已有本地图片的恢复；没有集成上游状态查询或上游取消。

SSH原生蒙版路线所需的 `scripts/catsco-masked-image2.mjs` 不在原ZIP中，能力检查会阻止缺少此脚本的路线。Big-LaMa仍需另行配置模型和GPU依赖。

## 关键模块

- `app/workbench.py`：草稿、范围预览、能力检查、幂等提交与安全恢复。
- `app/static/api.js`：接口与错误解析。
- `app/static/draft-store.js`：分项目/底图的本机副本与串行同步。
- `app/static/task-controller.js`：固定项目与任务的轮询订阅。
- `app/static/app.js`：工作台交互及画布状态。
